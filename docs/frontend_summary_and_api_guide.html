Executive Summary & Brand Architecture

Librix is an enterprise-grade library management application built with React 19, Vite, and Spring Boot 3. It enforces strict role separation between the Administrator Command Workspace and the Patron / Student Campus Workspace.

🛡️ Zero-Client-Cache Integrity

The frontend maintains zero mock arrays or persistent localStorage databases. Every single metric, catalog record, loan status, and fine calculation is fetched directly from the live backend database.

⚡ Automatic Expiry Redirection

JWT tokens are actively monitored client-side and intercepted on 401 Unauthorized responses. Expired tokens clear sessions and redirect users seamlessly to the login page with an alert banner.

🇮🇳 Indian Rupees (₹) Formatting

All catalog fines, active debt receivables, printable receipts, and penalty rates are uniformly standardized in Indian Rupees (₹) with en-IN localization.

🎨 Modern Librix Design

A sleek midnight and electric indigo theme with fluid typography, responsive data tables, glassmorphic cards, and custom printable transaction dockets.

Data Models & Frontend Normalization

How raw backend JSON representations are enriched and normalized in frontend memory before rendering:

1. Loan Normalization (enrichLoan)

The backend returns standard loan dates. The frontend enriches each loan with overdue status, delinquency duration, and live accrued fines: 

{
  "loanId": 42,
  "memberId": 7,
  "memberName": "Rahul Sharma",
  "bookId": 108,
  "bookTitle": "Clean Architecture",
  "issueDate": "2026-10-10",
  "dueDate": "2026-10-18",
  "returnDate": null,
  "status": "ACTIVE",
  "isOverdue": true,           // Computed: today > dueDate && status === 'ACTIVE'
  "daysOverdue": 11,            // Computed: days past due date
  "fine": 0,                    // Backend fine field (settled upon return)
  "accruedFine": 55             // Computed: 11 days * ₹5/day rate = ₹55
}

2. Book Normalization (normalizeBook)

Normalizes total vs available copies returned from the Spring Boot entity to guarantee consistent stock representations: 

{
  "bookId": 108,
  "title": "Clean Architecture",
  "author": "Robert C. Martin",
  "isbn": "978-0134494166",
  "totalCopies": 10,
  "availableCopies": 8
}

JWT Security & Token Expiry Flow

Authentication is safeguarded by a multi-layered security cycle that guarantees expired tokens are never sent and sessions terminate cleanly:

1. Pre-Flight Token Inspection

Before any request leaves client.js, authService.isTokenExpired(token) decodes the JWT exp claim. If expired, the request is aborted, local session cleared, and browser redirected.

2. Backend 401 Interception

If Spring Boot's JwtAuthenticationFilter rejects a token as expired, client.js catches HTTP 401, broadcasts an auth:expired event, clears storage, and routes to /login?expired=true.

3. Proactive Idle Timer

In AuthContext.jsx, a dynamic setTimeout fires exactly when (exp * 1000 - Date.now()) <= 0, logging out the user if they remain idle on a page past the expiration timestamp.

4. Route Guard Re-Validation

ProtectedRoute.jsx verifies both isAuthenticated and !isTokenExpired(token) on every client-side page navigation.

Performance Tuning & Latency Elimination

Specific optimizations implemented in Vite and the frontend pipeline that reduced build times from 10.31s to 2.46s and eliminated UI lag:

Bottleneck Area Root Cause Optimization Implemented Result
Windows Proxy Latency Vite dev proxy targeted http://localhost:8080. Node.js on Windows attempted IPv6 (::1) first, causing 300ms–1500ms connection timeouts. Updated proxy target to IPv4 loopback http://127.0.0.1:8080. Instant API response routing (0ms DNS overhead).
Vite Dev HMR Overhead lucide-react exports over 1,500 icon modules. Without pre-bundling, Vite served hundreds of individual HTTP ES modules. Added optimizeDeps.include: ['lucide-react', 'react', 'react-dom', 'react-router-dom'] in vite.config.js. Pre-compiled into a single esbuild bundle on start.
Artificial Code Lag LoginPage.jsx had a hardcoded setTimeout(..., 700) delay; App.jsx had setTimeout(..., 600). Removed artificial pauses to provide instant 100ms micro-transitions. Snappy, responsive navigation.
Dashboard Payload Dashboard requested 100 full loan records alongside books and patrons just to count active items. Reduced initial pagination size to 25 records. 75% reduction in initial JSON transfer size.
