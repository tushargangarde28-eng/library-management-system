# Library Management System

A REST API project for managing library books, members, and book borrowing/return operations.

## Project Overview

This project is being developed as part of a software development internship. The goal is to build a backend REST API using Java and Spring Boot, with MySQL for data persistence.

## Technology Stack

- **Java:** 21
- **Build Tool:** Maven
- **Backend Framework:** Spring Boot 3.x
- **API:** Spring Web
- **Persistence:** Spring Data JPA
- **Validation:** Jakarta Bean Validation
- **Database:** MySQL
- **Version Control:** Git and GitHub

## Planned Core Functionality

- Book management
- Library member management
- Book borrowing and returning
- Inventory consistency
- Input validation and error handling
- Automated testing and API documentation

*Features are subject to the approved internship guide and mentor-confirmed requirements.*
